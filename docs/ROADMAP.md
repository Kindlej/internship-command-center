# Roadmap

## Reliability
- Persist generated document paths/version metadata in SQLite.
- Add stronger semantic job-description deduplication.
- Add company application-frequency guardrails.
- Harden browser-assistant stop conditions and recovery.
- Expand unit/integration tests around state transitions and source parsing.

## Application intelligence
- Cost per built application and cost per interview analytics.
- Resume-version outcome comparisons.
- Interview-stage and days-to-response reporting.
- Follow-up reminders and weekly digest.
- Interview-prep workflow generated from the exact job description and verified profile.

## Product/UI
- Continue moving the landing experience toward a true pipeline board.
- Add richer build progress/status feedback.
- Add resume diff/revision inspection.
- Improve responsive layout and accessibility checks.
- Add a privacy-safe public demo mode using synthetic candidate/job data.

## Discovery
- Expand curated public ATS coverage while preserving provider terms/security boundaries.
- Improve source-health diagnostics and stale-source detection.
- Add target-company watchlists and source quality scoring.

## Non-goals
- No CAPTCHA/security bypasses.
- No password collection.
- No fabricated candidate facts.
- No autonomous final application submission.
