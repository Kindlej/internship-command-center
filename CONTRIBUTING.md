# Contributing

Internship Command Center is currently a personal project, but changes should follow the same engineering rules used by the application itself.

## Development rules

1. Never commit real candidate profiles, application answers, databases, browser sessions, generated applications, attachments, or API keys.
2. Keep final application submission outside automation authority.
3. Do not add CAPTCHA, login-wall, or provider-security bypasses.
4. Generated résumé/application claims must trace back to verified candidate facts.
5. Prefer public documented job-board interfaces and normal browser account flows.
6. Add or update tests for parsing, scoring, state transitions, and safety boundaries when behavior changes.
7. Keep UI changes responsive and usable in both dark and light themes.

## Pull requests

Keep changes focused, describe the user-facing behavior, call out privacy/safety implications, and include test evidence when practical.
